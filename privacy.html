ClipFarm privacy policy

Last updated: 17 November 2026

Who uses ClipFarm

ClipFarm is a private tool run by its owner on their own computer. Only the owner's own Google account can sign in.

What Google data it uses

With the owner's permission, ClipFarm uses the YouTube Data API to:

  • upload videos to the owner's YouTube channel (scope youtube.upload);
  • read that channel's own video list, video status and view counts (scope youtube.readonly).

It does not access email, contacts, files or any other Google data.

Where data is stored

The sign-in token and the video records are stored only on the owner's computer. Nothing is sent to any server run by ClipFarm, because there isn't one. No data is sold, shared or used for advertising.

Google API Services User Data Policy

ClipFarm's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove ClipFarm's access at any time at myaccount.google.com/connections. Deleting the ClipFarm folder on the computer deletes all stored data.
